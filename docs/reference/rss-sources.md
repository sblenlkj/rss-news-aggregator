# Русскоязычные RSS для ручного тестирования

Каталог подготовлен по предоставленному списку, с добавлением РИА Новости. Интерфакс исключён из набора из-за таймаутов при загрузке. **Четыре внешних источника плюс наш локальный тестовый RSS автоматически регистрируются при запуске без скачивания новостей** (`application/rss/bootstrap.py`). Остальные — кандидаты для ручной регистрации. Некоторые адреса могут возвращать 3xx/403/404 или HTML вместо RSS — окончательная проверка происходит в нашем приложении. Наш `FeedparserReader` пока не следует редиректам.

## Первая проверка

После запуска проверить `GET /api/v1/sources` и `GET /api/v1/articles`. Дефолтные: **РИА Новости**, **Хабр — все статьи**, **Коммерсантъ — Наука**, **МК — Наука** и наш тестовый RSS. Остальные добавлять через `POST /api/v1/sources` только при необходимости.

## Добавление вручную в Swagger

1. Запустить `uv run uvicorn news_aggregator.main:app --reload --port 8000`, открыть http://127.0.0.1:8000/docs.
2. Найти `POST /api/v1/sources`, нажать **Try it out**.
3. Вставить JSON для выбранного канала, например:

```json
{"url": "https://ria.ru/export/rss2/index.xml"}
```

4. Нажать **Execute**. HTTP 201 означает регистрацию источника. В ответе проверить `last_success_at` / `last_error`: первая загрузка могла завершиться неудачно.
5. Если нужно, запустить `POST /api/v1/sources/{source_id}/refresh`, затем открыть `GET /api/v1/articles`.
6. Сравнить новости двух тематик через `POST /api/v1/search` и персональные `source_ids`. Для русского языка попробовать поиск «исследования», «учёные», «политика» и опцию Navec.

По локальной проверке 22.11.2026 рабочие адреса из bootstrap возвращали 20 (РИА), 40 (Хабр), 2 (Коммерсантъ — Наука) и 50 (МК — Наука) статей. Число статей меняется со временем.

**Startup bootstrap включён:** создаёт только отсутствующие источники без сетевых запросов, сохраняя идентификаторы. Для новостей используйте ручное обновление или polling. Фоновый polling регулируется отдельно через `NEWS_POLL_INTERVAL_SECONDS`, по умолчанию выключен. SQLite вручную не изменять.
